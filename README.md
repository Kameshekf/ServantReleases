# ServantMod Releases

Official compiled binary releases of **ServantMod** for Minecraft Fabric.

### Supported Environments
- **Platforms:** Windows, Linux, macOS (Apple Silicon M-series and Intel x86_64)
- **Minecraft Versions:** 1.21.10, 1.21.11, 26.3

### Auto-Update Mirrors
- Primary CDN: `https://cdn.servant-ru.online/servantmod.jar`
- Direct Web: `https://servant-ru.online/api/mod/servantmod.jar`
- GitHub Releases: `https://github.com/Kameshekf/ServantReleases/releases`
